# Mailspring WhiteSur Dark Theme (Modernized)

A refreshed WhiteSur-inspired dark theme for Mailspring with:

- Modern blue-violet accent gradients
- Softer panel contrast for reduced eye strain
- Rounded cards and subtle depth shadows
- Cleaner sidebar, thread list, and message surfaces
- Updated focus rings and search/input states

Install by copying this theme folder into your Mailspring themes directory and selecting **Whitesur Dark Variant** in Mailspring theme settings.
